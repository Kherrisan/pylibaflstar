# RSC 抽取流程优化

状态：旧版已实施并核验（2026-11-01）；当前上下文与模型契约以 [pipeline.md](../docs/pipeline.md) 为准。本次契约调整未运行测试。

## 目标

减少无效工具调用和重复检索，提供焦点 block 已完成的 object 产物，并允许 LLM
省略指定空字段。该优化保持当时的最终输出契约、阶段顺序和并发配置。修改仅限根目录 `rsc/`，不修改 `third-party` 中的副本。

## 1. 修正工具说明与参数 schema

- 使用 PydanticAI `Tool.prepare`，根据当前运行配置生成 LLM 可见的参数上限及
  英文说明。每次深拷贝工具定义，避免并发运行使用不同配置时互相污染。
- 为 `top_k`、`lookup_object.limit/depth` 提供实际最大值，为 `keywords` 提供
  实际数量上限。保留运行时检查；修改模型可见 JSON Schema 不替代本地校验。
- `top_k`、`lookup_object.limit` 允许省略或传 `null`，Python 解析为
  `min(8, max_search_results)`。说明明确实际范围及默认行为；显式越界值仍报错。
- 查询词、关键词及对象名称添加非空字符串约束，并保留现有运行时词项检查。
- `search_objects` 的英文说明明确：`kind` 本身不能构成查询；必须提供非空
  `query` 或非空 `filters`；filters 必须同时指定 kind。列出合法过滤字段及简短
  示例。跨参数条件继续由运行时检查，不增加影响提供商兼容性的根级组合 schema。
- 分页说明明确：沿用原查询参数，仅使用该查询返回的 cursor；分页大小不等于
  必须遍历结果的数量。其余工具说明应与已有范围、数量和预算检查一致。
- 所有 docstring、注解说明和 `Field(description=...)` 使用英文。

## 2. 提供焦点 block 的 object 产物

- interaction 的焦点 `BlockArtifact.compile_result.objects` 附带同一 block
  已完成的 object 抽取结果，沿用现有名称刷新和精简投影。
- 原样表达 object 抽取的成功、空结果、部分成功或失败状态；缺少产物时不虚构
  内容，不能因为 object 结果为空就跳过 interaction。
- 仅增加同一焦点 block 的上一阶段产物可见性。object 阶段和同阶段的历史、
  后文及跨列表隔离规则继续适用；不扩大后文 block 的产物可见范围。
- window 中重复 block 和重复定义继续去重，不增加模型调用。

## 3. 将强制检索改为按需检索

- 提示词要求先使用已有原文和定义；信息不足、名称不明确或需要核对概念时，
  再自主检索。上下文足够时可直接返回结果或空集合。
- 取消新建 object、step、dependency 前必须完成搜索的提交门槛，删除 `_queried`
  等仅服务该门槛的逻辑；不要求 Agent 为查重而读尽全部分页。
- 保留名称复用提示、精确重复去重、现有 step ID 分配和后续 link。
- 修改已有定义时，继续检查完整定义是否已提供，并保留追加与修订权限约束；
  上下文已有完整定义时不要求额外调用查询工具。
- 保留有实际用途的工具调用审计及分页行为，不以搜索是否完成拒绝新建事实。

## 4. 允许省略指定空字段

仅在 LLM 响应模型中设置默认值：

| 字段 | 省略后的值 |
| --- | --- |
| `condition` | `""` |
| `field_relations` | `[]` |
| `unresolved` | `[]` |

- 覆盖抽取、补全和 link 响应中包含这些字段的类型。
- Pydantic 解析后补齐默认值，提交、持久化及最终输出仍包含完整字段；最终发布
  schema 不把最终模型字段改成可缺省。当前契约版本为 7.0.0。
- 省略表示空值，不表示沿用已有值；非空内容仍须返回，已有事实的保护规则继续
  适用。空值不允许改用 `null`，其他字段的必填要求保持现有契约。
- 提示词明确允许省略这些空字段，不恢复已删除的 ID、effects 或 evidence。

## 5. 测试与验收

- 用 FunctionModel 检查实际发送的工具 schema，覆盖默认配置及结果上限为 2 的
  配置；验证有效边界、超限、参数省略或 null、自定义默认值及跨运行配置隔离。
- 覆盖合法查询、合法 filters、仅传 kind、空白查询、空关键词和分页 cursor。
- interaction 首次请求即包含焦点 object 产物；覆盖空、失败和部分成功状态、
  去重、零上下文数量配置，以及同阶段后文和跨列表隔离。
- 上下文足够时，零工具调用可提交新 object、step、dependency；按需查询后复用
  的路径也继续通过。修改已有定义的读取与追加约束保留有效回归。
- 三类指定字段省略后正确补齐，显式非空值保持完整，错误类型及 null 仍被拒绝；
  最终模型通过现有 schema 校验。
- 删除或重写只服务强制检索的过时测试，不删除仍有效的隔离、审计、权限、
  ID、失败恢复、并发稳定性及缓存回归。
- 运行相关测试、完整 RSC 测试和 Ruff；不启动真实模型调用。
